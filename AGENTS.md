# NOVA AI agent instructions

- Read README.md and this specification before changing architecture.
- Inspect the repository before editing; preserve working behavior.
- Never claim a feature or test works unless implemented and verified.
- Never fabricate AI responses, citations, live data, or action success.
- Keep provider API keys server-side; never expose secrets to Vite.
- Never silently switch provider or incur paid API usage.
- Validate all external input and treat model output as untrusted.
- Do not execute generated code on the API host.
- Add tests for backend behavior and run tests after changes.
- Implement one milestone at a time and report completed, partial, blocked, and untested items.
